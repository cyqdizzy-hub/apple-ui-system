# Changelog

## 1.0.0 — 2026-11-16

- Established the Apple-inspired UI System as a reusable design standard based on Flow Studio V1.1.
- Published the integrated Codex Skill `apple-ui-system`.
- Added guidance for information hierarchy, typography, semantic tokens, selective Liquid Glass, Motion, accessibility, responsive behavior, performance, and project adoption.
- Added CSS starter templates for tokens, glass fallback, and motion preferences.
- Added a safe Windows installer that does not overwrite an existing Skill unless `-Force` is supplied; forced updates create a timestamped backup.
- Retained explicit cross-browser and full accessibility audit limitations.
