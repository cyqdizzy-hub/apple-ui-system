# Codex 项目接入任务模板

请使用 `$apple-ui-system`，依据本项目的 Apple-inspired UI System v1.0.0 设计标准开展工作。

先检查当前技术栈、品牌规范、页面结构、CSS Token、路由/API、Git 状态和现有测试。读取 `references/` 中与任务相关的规范，不要盲目覆盖原有样式。

本次范围：**[填写页面或模块]**。

目标：
- 优化信息层级、排版、留白、组件状态和响应式布局。
- 在导航、工具栏、Popover 等功能层选择性应用 Liquid Glass；主要内容保持清晰稳定。
- 使用可中断、可逆的目的性动效；支持 reduced-motion 和不透明材质降级。
- 保留业务逻辑、数据、API、路由语义、权限和既有操作。

实施步骤：
1. 建立 Git 分支/备份，记录现状截图和测试基线。
2. 审计现有 Token 与上游变量冲突，建立项目级语义映射。
3. 先完成一个独立试点，不扩展到无关页面。
4. 完成桌面/平板/手机、明暗主题、键盘、减少动效、降低透明度和快速重复操作测试。
5. 提供前后截图、交互录屏、测试报告、变更清单和未解决问题。
6. 停在人工验收门禁。只有用户明确确认 `UI_MOTION_ACCEPTED` 后才推广。
